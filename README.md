## Problems Completed

| No. | Problem | Language | Time Complexity | Space Complexity |
|---|---|---|---|---|
| 1 | Diagonal Difference | Java | O(n) | O(1) |
| 2 | Dynamic Array | Java | O(n + q) | O(n) |
| 3 | Time Conversion | Java | O(1) | O(1) |
| 4 | Compare the Triplets | Java | O(1) | O(1) |
| 5 | Sparse Arrays | Java | O(N + Q) | O(N) |

## 1. Diagonal Difference

Calculates the absolute difference between the sums of the primary and secondary diagonals of a square matrix.

## 2. Dynamic Array

Uses dynamic sequences and XOR-based indexing with `lastAnswer` to process the queries efficiently.

## 3. Time Conversion

Converts a 12-hour AM/PM time format into the 24-hour format.

## 4. Compare the Triplets

Compares Alice's and Bob's scores element by element and calculates their respective scores.

## 5. Sparse Arrays

Uses a `HashMap` to store string frequencies and efficiently answer the frequency of each query.

## Algorithmic Techniques Learned

- Array traversal
- Matrix traversal
- Dynamic arrays
- XOR-based indexing
- HashMap frequency counting
- String manipulation
- Query processing
- Time and space complexity analysis
